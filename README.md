# calculatorine
Here is my very first calculator using the trio HTML5, CSS and JS

## Fonctionnalités
- Opérations de base (+, -, *, /)
- Inversion de signe (+/-)
- Calcul de racine carrée (√)
- Effacement total (C) et suppression du dernier caractère (Del)
- Design moderne et responsive avec CSS Grid et Flexbox

## Technologies utilisées
- HTML : Structure du projet
- CSS : Design et mise en page (Flexbox & Grid)
- JavaScript : Logique de calcul
